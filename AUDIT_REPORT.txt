FINAL RECOMMENDATION
--------------------------------------------------------------------------------
RECOMMENDATION: SHIP AS OPT-IN ONLY (DISABLED BY DEFAULT).
Due to the client-side SpeechRecognition substring match triggers (hacker/radar/house), there is a high false-positive rate (40%) when talking naturally near the mic. Leaving this enabled by default would cause disruptive false activations during presentations. 

To resolve this, we modified the code (commit 4b1701b -> next) to make the Wake-Word toggle start as MUTED by default on page load. Presenters can manually toggle the feature on (active state) during the interactive demo phase, keeping the main presentation risk-free.
